# Tianxu Peng · Research homepage

Use Node.js 24. Run `npm ci` and `npm run dev` for local editing. Run `npm run build` to produce the static site in `dist/`.

The publication list and homepage use `src/data/publications.json`. Use one entry for each published paper and link to the publisher or conference proceedings.

For the GitHub Pages user site, choose GitHub Actions under Settings → Pages. The included workflow builds on pull requests and deploys from `main`. This project only contains the new public site.
